## 첫 검증에서 수정한 부분

이슈 #1의 첫 실행에서는 기능 검증이 통과했지만 checker가 PR 생성 전 원격 CI를 요구하여 ESCALATE_HUMAN을 반환했습니다. 로컬 승인 → commit/PR 생성 → 정확한 SHA의 CI 확인으로 검증 단계를 분리했습니다.

실패 이력을 유지했고 공식 loop-context가 이슈 #1의 토큰 예산 초과를 차단했습니다. 해당 제한은 늘리지 않았습니다. 이슈 #1은 로컬 needs-human 상태이며 기본 start에서 건너뜁니다. 이슈 #2로 수정한 실행 경로를 검증했습니다.
